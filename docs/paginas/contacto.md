# Página: Contacto

**Objetivo (1 línea):** Captar consultas y mostrar la ubicación del centro.

**Secciones (en orden):**

1. Header
2. Encabezado
3. Formulario (Nombre, Correo, Mensaje, Enviar)
4. Datos de contacto directo (dirección, teléfono, fax, email)
5. Mapa de ubicación
6. Footer

**CTA principal:** "Enviar" (formulario)
