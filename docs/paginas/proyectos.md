# Página: Proyectos

**Objetivo (1 línea):** Mostrar proyectos de investigación aplicada, con
estado y resultados.

**Secciones (en orden):**

1. Header
2. Encabezado ("Proyectos" + bajada)
3. Grid/lista de proyectos (título, estado, descripción corta, enlace)
4. CTA final
5. Footer

**CTA principal:** "Ver más" por proyecto → detalle

**Notas de diseño:**

- Badge de estado por tarjeta (ej. "Activo") con `radius-pill`
- Ejemplos reales: Gestión Integrada de Zonas Costeras · Monitoreo
  Ambiental Marino · Cambio Climático y Adaptación
