# Página: Docencia

**Objetivo (1 línea):** Presentar la oferta de diplomados y cursos de
posgrado del centro.

**Frames:** `CEAC v7 - Docencia (Desktop)` y `CEAC v7 - Docencia (Mobile)`.

**Secciones (en orden):**

1. Header (con "Docencia" marcado).
2. Encabezado de página: foto de clase, "Inicio › Docencia", título y
   bajada.
3. **Qué ofrecemos:** una tarjeta para **Diplomados** y otra para **Cursos
   de posgrado**, con foto, ícono, descripción y tres características con
   check (duración, certificado, trabajo final o talleres).
4. **Próximos programas:** filtros Todos / Diplomados / Cursos de posgrado
   y tarjetas de programa con tipo, estado ("Inscripción abierta" con punto
   azul o "Próximamente" con punto gris), título, duración, modalidad,
   fecha de inicio y "Ver programa".
5. Ola → franja azul "¿Te interesa alguno de nuestros programas?" con el
   botón "Solicitar información".
6. Ola → Footer.

**CTA principal:** "Solicitar información" → Contacto (motivo "Docencia y
posgrado").

**Notas:**

- Solo se imparten diplomados y cursos de posgrado: no hay maestrías.
- Los programas, duraciones, modalidades y fechas son de relleno.
