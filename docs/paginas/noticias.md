# Página: Noticias

**Objetivo (1 línea):** Mantener informados sobre proyectos, foros y
colaboraciones.

**Secciones (en orden):**

1. Header
2. Encabezado
3. Lista de noticias (fecha, título, bajada, "Leer más")
4. Footer

**CTA principal:** ninguno — cada noticia enlaza a "Leer más"

**Notas de diseño:**

- Fecha en `font-label` (IBM Plex Mono), formato "DD MES AAAA"
- 3 noticias visibles por defecto, con opción de ver más
