# 1. Identidad de marca

| Campo | Valor |
|---|---|
| Nombre de empresa | CEAC — Centro de Estudios Ambientales de Cienfuegos |
| Dominio | Pendiente de definir |
| Rubro / qué hace | Centro de investigación ambiental: proyectos, laboratorio de ensayos, docencia/posgrado y servicios de consultoría en Cienfuegos, Cuba |
| Tono (3 adjetivos) | Científico, confiable, comprometido (con la sostenibilidad) |
| A evitar | Look corporativo genérico sin identidad territorial/ambiental |
| Idiomas | Solo español |
| Referencias de estilo | El propio proyecto ("CEAC Home Modern") es la referencia base: azul institucional + verde ambiental, iconografía ambiental sutil |

**Por qué importa:** estas tres líneas (tono, qué evitar y referencias) son
las que más rápido evitan que el diseño termine pareciendo una plantilla
corporativa genérica. Toda decisión de UI (copys, iconografía, ilustración)
se puede chequear contra esto: ¿suena científico y confiable sin perder
calidez? ¿se nota que es un centro ambiental y no un banco?

Ver también: [02-tokens-de-diseno.md](02-tokens-de-diseno.md) (cómo se traduce
este tono a colores y tipografía concretos).
